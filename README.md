# HALO Night

One-page site for HALO, a night of sound, light, and a long table at Gudang Empat, Sunda Kelapa — Saturday 12 December 2026.

- Countdown to doors
- Agenda, speakers, ticket tiers, and a venue plan
- RSVP holds saved in the browser, with live capacity

```bash
npm install
npm run dev
```
